# PostWave

Production-ready web application for scheduling Instagram posts with team collaboration and role-based access control. Built with Python Flask and vanilla JavaScript.

## Features

- 🔐 Multi-user authentication with JWT
- � Instagram Business API integration
- 📅 Automated post scheduling with background tasks
- 🖼️ Multi-image carousel posts (1-20 images)
- 👁️ Live Instagram preview before publishing
- 📊 Dashboard with post statistics
- 🐳 Docker deployment support

## Quick Start

### Docker (Recommended)

```bash
# Set up environment
cp .env.example .env

# Edit .env with your Instagram API credentials
# Start the app
docker-compose up -d

# Open http://localhost:5000
```

### Local Development

```bash
# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env

# Run the app
python app.py

# Open http://localhost:5500 in your browser
```

## Setup & Configuration

### Prerequisites

- Python 3.11 or higher
- Docker (optional)
- Instagram Business Account
- Facebook Developer Account

### Environment Variables

Create a `.env` file in the root directory:

```env
# Flask Configuration
FLASK_ENV=production
SECRET_KEY=<generate-with: openssl rand -hex 32>
JWT_SECRET_KEY=<generate-with: openssl rand -hex 32>

# Database
DATABASE_URL=sqlite:///postwave.db

# Instagram API
INSTAGRAM_APP_ID=your-app-id
INSTAGRAM_APP_SECRET=your-app-secret
INSTAGRAM_API_VERSION=v19.0

# Email/SMTP Configuration (for team invitations)
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USE_TLS=true
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_FROM_EMAIL=noreply@postwave.com
MAIL_FROM_NAME=PostWave

# Server
HOST=0.0.0.0
PORT=5500

# File Upload
MAX_CONTENT_LENGTH=52428800  # 50MB
UPLOADS_PATH=./uploads
```

### Generate Secure Keys

```bash
# macOS/Linux
openssl rand -hex 32

# Or use Python
python3 -c "import secrets; print(secrets.token_hex(32))"
```

## Instagram Connection Setup

### Prerequisites

1. **Instagram Business Account** (Required)
   - Go to Instagram Settings → Account → Switch to Professional Account
   - Select "Business" as the account type
   - Your account will be converted to a Business Account

2. **Facebook Developer Account** (Required)
   - Create a free account at [developers.facebook.com](https://developers.facebook.com)
   - Create a new Facebook App
   - Add "Instagram Graph API" product to your app

### Step-by-Step Setup

#### 1. Create Facebook App and Get Credentials

1. Go to [developers.facebook.com](https://developers.facebook.com)
2. Click "My Apps" → "Create App"
3. Choose app type: "Business"
4. Fill in app details (name: "Postwave" or similar)
5. Go to **Settings → Basic** and copy:
   - **App ID**
   - **App Secret** (click "Show")

#### 2. Add Instagram Graph API Product

1. In your app dashboard, click **Products**
2. Search for "Instagram Graph API"
3. Click "Add" to add it to your app

#### 3. Request Permissions

1. Go to **Settings → App roles**
2. Ensure you have **Admin** role
3. The following permissions will be available for your app:
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_show_list`
   - `pages_read_engagement`

#### 4. Generate User Access Token (via Facebook OAuth)

⚠️ **IMPORTANT: Use Facebook OAuth, not Instagram direct login**

1. Go to [Facebook Graph API Explorer](https://developers.facebook.com/tools/explorer/)
2. Select your **Postwave app** from the top-right dropdown
3. Click **"Get Token"** → **"Get User Access Token"**
4. Select permissions:
   - ✓ `pages_show_list`
   - ✓ `pages_read_engagement`
   - ✓ `instagram_basic`
   - ✓ `instagram_content_publish`
5. Click **"Generate Access Token"**
6. Accept permissions when prompted
7. **Copy the generated token** (the long string starting with `IGAA...`)

#### 5. Configure in PostWave

Add to your `.env` file:

```env
INSTAGRAM_ACCESS_TOKEN=<your-token-from-facebook-oauth>
INSTAGRAM_APP_ID=<your-app-id>
INSTAGRAM_APP_SECRET=<your-app-secret>
INSTAGRAM_API_VERSION=v24.0
```

#### 6. Connect in Settings

1. Open PostWave → Settings → Instagram
2. Click "Connect Instagram Account"
3. Your account should connect automatically
4. You'll see your Instagram Business Account ID and username

### Token Management

**Token Types:**
- **Short-lived tokens**: Expire in ~1-2 hours (generated from Graph API Explorer)
- **Long-lived tokens**: Expire in ~60 days (auto-generated by PostWave)

PostWave automatically converts short-lived tokens to long-lived tokens on connection.

### Troubleshooting

**"Invalid platform app" or "Insufficient Developer Role"**:
- Ensure you're using **Facebook OAuth** (not Instagram direct login)
- Verify your Instagram account is a **Business Account** (not Creator or Personal)
- Confirm you have **Admin role** in the Facebook app

**"Invalid OAuth access token"**:
- Token may be expired or invalid
- Regenerate from [Facebook Graph API Explorer](https://developers.facebook.com/tools/explorer/)
- Ensure you're logged into the correct Facebook account

**"No Instagram Business Account found"**:
- Verify your Instagram account is a Business Account
- Ensure your Facebook Page is linked to your Instagram account
- Try regenerating the access token with all required permissions

**Connection fails after setup**:
- Clear browser cache and cookies
- Log out completely and log back in
- Regenerate access token from Graph API Explorer

## First-Time Setup

On first launch, PostWave displays a registration page to create your admin account.

### Initial Setup

1. **Register Admin Account**
   - Username
   - Email  
   - Password

After setup completes, you'll be logged in and can:
- Access the dashboard
- Create and schedule posts
- View all scheduled posts

### Account Access Model

PostWave supports multiple access models:
- **Single-user mode**: One admin account manages all posts
- **Team collaboration**: Multi-team support with role-based access control (Super Admin, Team Leader, Team Member)
- **Post approval workflow**: Optional approval requirements for team members
- **Team invitations**: Email-based invitations with 7-day expiration

### Email Configuration

Email configuration is **optional** for basic functionality. However, it's **required** if you want to:
- Send team member invitations
- Enable automated notifications

To enable email features, configure your SMTP server in Settings:

```env
# Gmail Example
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USE_TLS=true
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password  # Use App Password for Gmail
MAIL_FROM_EMAIL=noreply@postwave.com
MAIL_FROM_NAME=PostWave
```

**Gmail Setup:**
1. Enable 2-Factor Authentication
2. Generate App Password: https://myaccount.google.com/apppasswords
3. Use the 16-character app password in `MAIL_PASSWORD`

## Using the App

### Creating a Post
1. Click "New Post" or press `Ctrl/Cmd + N`
2. Drag & drop or select images (up to 20 images total)
   - You can add images multiple times - they will be appended to your selection
   - Click to browse or drag & drop additional files
3. Write caption (2200 chars max)
4. Choose schedule time
5. Preview and click "Schedule Post"

### Keyboard Shortcuts
- `Ctrl/Cmd + N` - New Post
- `Ctrl/Cmd + D` - Dashboard
- `Ctrl/Cmd + P` - All Posts
- `Ctrl/Cmd + S` - Settings
- `ESC` - Close Modal

## API Endpoints

### Authentication
- `POST /api/auth/register` - Register admin account
- `POST /api/auth/login` - Login and get JWT token
- `POST /api/auth/refresh` - Refresh access token
- `GET /api/auth/me` - Get current user info

### Posts
- `GET /api/posts` - List posts
- `POST /api/posts` - Create new post
- `GET /api/posts/<id>` - Get post details
- `PUT /api/posts/<id>` - Update post
- `DELETE /api/posts/<id>` - Delete post

### Instagram Connection
- `POST /api/instagram/connect` - Connect Instagram account
- `GET /api/instagram/media` - Get media list

### Users
- `GET /api/users/profile` - Get user profile
- `PUT /api/users/profile` - Update user profile

## Deployment

### Production Deployment

1. Set `FLASK_ENV=production` in `.env`
2. Use a production WSGI server (Gunicorn, uWSGI)
3. Set up reverse proxy (Nginx, Apache)
4. Enable HTTPS
5. Configure database (PostgreSQL recommended for production)

### Docker Deployment

```bash
# Build and run with Docker
docker-compose up -d

# View logs
```

## Troubleshooting

### App won't start
```bash
# Check Python version (need 3.11+)
python3 --version

# Reinstall dependencies
pip install -r requirements.txt --force-reinstall

# Check ports (5000 should be free)
lsof -i :5000  # Mac/Linux
netstat -ano | findstr :5000  # Windows
```

### Instagram posting fails
- Verify Instagram Business Account
- Check Facebook Page is linked to Instagram
- Ensure Access Token is valid (they expire!)
- Confirm Media URLs are publicly accessible
- Check Instagram API rate limits

### Images not uploading
- Max 20 images per post
- Supported: JPG, PNG, GIF
- Auto-optimized to 1080px max, 8MB limit
- Check `uploads/` folder permissions

### Docker issues
```bash
# Rebuild completely
docker-compose down -v
docker-compose up -d --build

# Check logs
docker-compose logs -f

# Check container status
docker-compose ps
```

## API Limits

**Instagram Graph API:**
- 25 API calls per user per 24 hours
- 200 API calls per app per hour
- Media must be publicly accessible URLs
- Carousels: 2-10 items

**App Limits:**
- Max 20 images per post
- Caption: 2200 characters
- Image size: Auto-optimized to 8MB, 1080px
